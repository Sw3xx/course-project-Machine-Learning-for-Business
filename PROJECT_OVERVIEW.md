# Project overview

RepayPro is presented in the course report as a repayment-probability prediction and risk-support concept for consumer-finance workflows. The modeling work evaluates Logistic Regression, Decision Tree, Random Forest, XGBoost, and MLP classifiers using the binary target `loan_paid_back`.

The supplied report discusses dataset exploration, preprocessing, model comparison, feature importance, and SHAP analysis. The source archives contain the model scripts and selected text outputs. The original PDF report and source dataset are not bundled in this GitHub-ready package because the report contains team member names/student identifiers and the dataset's redistribution permission has not been established.
